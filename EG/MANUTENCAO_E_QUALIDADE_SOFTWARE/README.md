# Manutenção e Qualidade de Software - Resumo

Este material apresenta de forma resumida e objetiva os conceitos fundamentais sobre **Manutenção de Software** e **Qualidade**, baseados nas boas práticas de Engenharia de Software.

---

##  Manutenção de Software

A **manutenção de software** é a atividade contínua de modificar um sistema após sua entrega inicial. Essa modificação ocorre por diversos motivos, como:

- Correção de defeitos.
- Adição de novas funcionalidades.
- Adaptação a novas plataformas ou ambientes.
- Melhoria da qualidade interna do código (**refatoração**).

**Importante:**  
A manutenção pode representar até **90% dos custos totais** de um projeto de software ao longo de sua vida útil, o que destaca a necessidade de boas práticas de desenvolvimento e qualidade desde o início.

---

## Tipos de Manutenção

- **Corretiva:** Correção de falhas e defeitos identificados.
- **Evolutiva:** Inclusão de novas funcionalidades.
- **Adaptativa:** Adequação do software a novos ambientes.
- **Perfectiva (Refatoração):** Melhorias internas para aumentar a qualidade e facilitar futuras manutenções.

---

## Qualidade de Software

### **Características de Qualidade:**

| Característica   | Descrição                                                                 |
|------------------|-------------------------------------------------------------------------|
| **Funcionalidade** | O sistema faz o que foi projetado para fazer?                          |
| **Usabilidade**    | O sistema é fácil de entender e utilizar?                              |
| **Confiabilidade** | O sistema funciona corretamente de forma consistente?                 |
| **Desempenho**     | O sistema responde e executa as funções no tempo esperado?            |
| **Portabilidade**  | O sistema pode ser transferido para outros ambientes facilmente?      |
| **Manutenabilidade** | O sistema é fácil de corrigir, melhorar ou adaptar?                  |
| **Segurança**      | O sistema protege contra acessos não autorizados e ataques?           |
| **Compatibilidade** | O sistema funciona corretamente em conjunto com outros sistemas?      |
